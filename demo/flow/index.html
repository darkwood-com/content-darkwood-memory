Un calcul, trois durées.

MÉMOIRE NAVIGATEUR

Cette version exécute du JavaScript et conserve un résultat dans localStorage. Elle ne crée aucune session PHP. La version Symfony du dépôt permet d’expérimenter une véritable session serveur.

01 / TEMPORAIRE

La variable est recréée lorsque vous rechargez la page.

02 / RÉUTILISÉ

Deux lectures partagent un calcul dans cette évaluation ; le cache est ensuite abandonné.

03 / CONSERVÉ

Ce résultat reste dans ce navigateur jusqu’à son effacement ou au nettoyage du stockage.

DARKWOOD/FLOW · v8.1.6

Un état qui passe réellement d’une étape à l’autre.

Le premier job additionne 4, 7 et 9. Les deux suivants réutilisent le total pour calculer une moyenne et ce qui reste sur 100. Flow compose les jobs et transporte cet état dans un Ip ; le calcul et les données restent de simples primitives PHP.

Ce résultat a été produit par PHP et la véritable bibliothèque pendant le build de cette page. GitHub Pages ne réexécute pas PHP. L’atelier interactif ci-dessus est une illustration JavaScript distincte.

Calcul du total

Lire le véritable exemple PHP exécutable
<?php

declare(strict_types=1);

require_once __DIR__.'/../vendor/autoload.php';

use Composer\InstalledVersions;
use Flow\FlowFactory;
use Flow\Ip;

$calculations = 0;
$result = [];
$flow = (new FlowFactory())->create(static function () use (&$calculations, &$result) {
    yield static function (array $state) use (&$calculations): array {
        ++$calculations;
        return $state + ['total' => array_sum($state['values'])];
    };
    yield static fn (array $state): array => $state + ['mean' => $state['total'] / count($state['values'])];
    yield static function (array $state) use (&$result): array {
        $result = $state + ['remaining' => 100 - $state['total']];
        return $result;
    };
});
$flow(new Ip(['values' => [4, 7, 9]]));
$flow->await();

$report = ['package' => InstalledVersions::getPrettyVersion('darkwood/flow'), 'calculations' => $calculations, 'result' => $result];
if (realpath($_SERVER['SCRIPT_FILENAME'] ?? '') === __FILE__) {
    echo json_encode($report, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE | JSON_THROW_ON_ERROR).PHP_EOL;
}
return $report;

Reproduire : nix develop -c php examples/flow-memory.php. À chaque exécution, l’état est neuf. Flow ne fournit ici ni sauvegarde durable, ni cache intersession : conserver le résultat exige un stockage choisi par l’application.
